# POWER OF KOJNER (RoundsMod)

Кастомный мод для игры **ROUNDS**, добавляющий уникальные карты с активными способностями, собственной системой слотов (`Q / E / F / V`), защитой от застревания в текстурах и сетевой синхронизацией через Photon.

## Архитектура проекта (Памятка, как всё устроено)

Проект разделен на 4 логических модуля, чтобы не смешивать UI карт, сетевую физику и патчи:

* **`MyMod.cs`** — точка входа BepInEx (`com.username.myfirstmod`). Инициализирует Harmony-патчи в `Awake()` и поочередно регистрирует карты через корутину в `Start()`.
* **`Cards/`** — описание карточек, статов и начисление компонентов при выборе:
  * `KojnerBaseCard.cs` — базовый класс для всех карт мода. Подгружает арты и защищает префаб от удаления при перезапуске матчей (`DontDestroyOnLoad` + `ArtRefresher`).
  * `KojnerActiveCard.cs` — базовый класс для активных карт. Вешает категорию `KojnerActiveSlot`, чтобы движок автоматически скрывал новые активные карты на драфте, когда все 4 слота (`Q/E/F/V`) заполнены.
* **`Components/`** — вся игровая и сетевая логика способностей:
  * `KojnerAbilityManager.cs` — менеджер 4 слотов (`Q`, `E`, `F`, `V`), обрабатывающий нажатия клавиш и рисующий HUD с таймерами перезарядки в верхнем левом углу.
  * `KojnerTeleportNetworkMono.cs`, `BlackHoleNetworkMono.cs`, `TimeTrackerComponent.cs`, `SatelliteShieldMono.cs` — сетевые компоненты способностей.
* **`Patches/`** — Harmony-патчи:
  * `HealthHandlerPatch.cs` — перехват `HealthHandler.TakeDamage` (перегрузка на 7 аргументов) для полной блокировки урона орбитальными щитами.
* **`Utils/`** — вспомогательные утилиты:
  * `AssetHelper.cs` — загрузка `.png` из `EmbeddedResource` с кэшированием и запасным артом (`kojner_power.png`).
  * `NetEventRegistry.cs` — детерминированный генератор уникальных кодов событий Photon (`100–194`) по строковому ключу, исключающий конфликты с другими модами.
  * `IKojnerAbility.cs` — общий интерфейс для привязки способностей к слотам `KojnerAbilityManager`.

## Как быстро добавить новую активную карту (Шпаргалка)

1. **Создай сетевой компонент** в `Components/`, унаследовав его от `MonoBehaviour, IOnEventCallback, IKojnerAbility`.
2. **Получи сетевой код** через `NetEventRegistry.GetCode("KojnerMod.YourAbilityName")` и добавь fallback на локальный вызов при `!PhotonNetwork.InRoom` (для работы в Sandbox).
3. **Зарегистрируй в слоте:** в методе инициализации компонента вызови:
   ```csharp
   var mgr = player.gameObject.GetComponent<KojnerAbilityManager>() ?? player.gameObject.AddComponent<KojnerAbilityManager>();
   mgr.TryBindAbility(this);
   ```
4. **Создай класс карты** в `Cards/`, унаследовав от `KojnerActiveCard`.
5. **Подключи файлы в `RoundsMod.csproj`** (блок `<Compile Include="..." />`), при необходимости добавь `.png` арт как `<EmbeddedResource Include="..." />` и вызови `CustomCard.BuildCard<YourCard>();` в `MyMod.cs`.

## Сборка и установка

1. Собери проект в Visual Studio (`Build Solution` -> `bin\Debug\RoundsMod.dll`).
2. Скопируй `RoundsMod.dll` в папку `ROUNDS\BepInEx\plugins\`.
3. **Зависимости для запуска:** `BepInEx`, `UnboundLib`, `ModdingUtils`.
